# GlossCheck — AI-чат с понятной админкой

Сделал для заказчика AI-чат на WordPress: человек задаёт вопрос, а сервис обращается к DeepSeek и показывает ответ. Можно вести историю переписки, а администратор сам управляет настройками чата — без разработчика.

Сайт **работал по адресу https://glosscheck.ru/**. Сейчас он недоступен. Почему заказчик решил его отключить, мне неизвестно. Код проекта остался здесь, на GitHub.

## Что умеет сервис

- Отвечает на текстовые вопросы через DeepSeek API.
- Сохраняет историю диалогов.
- Поддерживает гостей и зарегистрированных пользователей.
- Даёт администратору возможность смотреть чаты и управлять настройками AI.
- Ограничивает частоту запросов, длину истории и ответов, чтобы расходы на API не росли бесконтрольно.
- В клиентском проекте также была работа с фотографиями и документами: текст извлекался через **Tesseract OCR** и затем передавался в AI на анализ.

## Что заказчик меняет сам

В WordPress есть разделы «Настройки чата», «История чатов» и «Пользователи чата».

| Что можно изменить | Как это работает |
| --- | --- |
| Инструкции для AI | Отредактировать системный промпт: роль, тон общения и правила ответов |
| Модель | Указать модель DeepSeek |
| История | Изменить количество сообщений, учитываемых в контексте |
| Ответы | Изменить максимальное число токенов ответа |
| Лимиты | Ограничить число запросов в минуту, в том числе для отдельных пользователей |
| Переписка | Просмотреть историю чатов и пользователей |

Для изменения этих параметров не нужно открывать код. Новый промпт начинает действовать в новых диалогах; уже начатые продолжаются с прежними инструкциями.

## Как это устроено

```text
Пользователь на сайте
         |
         v
    Чат WordPress
         |
         +--- Текстовый вопрос -----------------------+
         |                                            |
         +--- Фото / PDF / документ                   |
                   |                                  |
                   v                                  |
             Tesseract OCR                            |
           извлекает текст                            |
                   |                                  |
                   +----------------------------------+
                                                      |
                                                      v
                                 Плагин GlossCheck DeepSeek Chat
                                 - системный промпт из админки
                                 - история переписки
                                 - лимиты запросов и токенов
                                                      |
                                                      v
                                                  DeepSeek API
                                                      |
                                                      v
                                                Ответ в чате
```

Смысл OCR в том, чтобы передать в AI **текст из изображения или документа**, а не сам файл. Это позволяет обойтись без более дорогой обработки картинки мультимодальной моделью, когда для ответа достаточно распознать текст.

**Уточнение по исходникам:** схема показывает возможности клиентского проекта, описанные в [портфолио GlossCheck](https://github.com/suyazov/affine-pages-backup/blob/main/affine/portfolio/Portfolio/GlossCheck.md). В опубликованной здесь версии плагина подтверждаются текстовый чат, DeepSeek API, история и админка. Код обработки файлов и Tesseract OCR в этом снимке репозитория отсутствует, поэтому из него одного проверить OCR нельзя.
